## Instruction Categories

- Load/Store
- Computational
- Jump and Branch
- Floating Point
- Memory Management
- Special

## Operands

- Each instruction is 32 bits
- Syntax is rigid -> 1 operator, 3 operands
- assembly operands are registers
- MIPS have 32 registers, each is 32 bits wide
